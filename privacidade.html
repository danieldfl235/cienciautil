Política de Privacidade

Ferramenta “Ciencia Util Publicacao” · atualizada em 14/10/2026 (TikTok incluído)

O que é

Uma ferramenta interna que usa os Serviços de API do YouTube para enviar vídeos ao canal Ciência Útil. Só o dono do canal a usa, com a própria Conta do Google. Ao usar a ferramenta, o usuário concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

Dados acessados

Com a autorização OAuth do dono do canal, a ferramenta usa os escopos youtube.upload e youtube.force-ssl para: enviar vídeos, definir a miniatura, enviar legendas e ler o nome e o ID do canal autorizado (para confirmar que é o canal certo). Ela não lê comentários, inscritos, mensagens, estatísticas nem dados de espectadores.

Uso, armazenamento e compartilhamento

Os dados servem apenas para publicar os vídeos do próprio canal. O token de autorização fica guardado só no computador do dono do canal. Nenhum dado da API do YouTube é enviado a servidores próprios, vendido ou compartilhado com terceiros, e não há cookies, anúncios nem rastreamento.

TikTok

No TikTok, a ferramenta usa o Login Kit e a Content Posting API com os escopos user.info.basic (ler o open_id e o nome da conta autorizada, para confirmar que é a conta @ciencia.util) e video.upload (enviar o vídeo do canal como rascunho, que o dono revisa e publica no app do TikTok). Nenhum outro dado do TikTok é lido; o token fica só no computador do dono do canal e pode ser revogado no app do TikTok, em Configurações e privacidade › Segurança › Apps com permissão. Vale também a Política de Privacidade do TikTok.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento na página de permissões da Conta do Google. Ao revogar, o token local deixa de funcionar e é apagado. Nenhum dado da API é mantido por mais de 30 dias além do próprio token.

Privacy Policy

“Ciencia Util Publicacao” is an internal tool that uses the YouTube API Services to upload videos to the Ciência Útil channel. Only the channel owner uses it, with their own Google Account. By using it, the user agrees to the YouTube Terms of Service and to the Google Privacy Policy.

Data accessed: with the owner's OAuth consent, the scopes youtube.upload and youtube.force-ssl are used to upload videos, set thumbnails, upload captions and read the authorized channel's name and ID. No comments, subscribers, messages, analytics or viewer data are read.

Use, storage and sharing: data is used only to publish the channel's own videos. The authorization token is stored only on the owner's computer. No YouTube API data is sent to other servers, sold or shared with third parties. There are no cookies, ads or tracking.

TikTok: the tool uses Login Kit and the Content Posting API with the scopes user.info.basic (read the authorized account's open_id and display name, to confirm it is @ciencia.util) and video.upload (send the channel's video as a draft that the owner reviews and posts in the TikTok app). No other TikTok data is read; the token stays only on the owner's computer and can be revoked in the TikTok app under Settings and privacy › Security › Apps with permission. The TikTok Privacy Policy also applies.

Revocation and deletion: access can be revoked at any time on the Google Account permissions page; the local token then stops working and is deleted. No API data is kept for more than 30 days besides the token itself.
