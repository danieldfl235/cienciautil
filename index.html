Ciência Útil

estudos que servem para a sua vida, explicados em minutos

Ciência Útil é um canal de divulgação científica no YouTube (@cienciautil) e no TikTok (@ciencia.util). Cada vídeo explica um artigo publicado em revista científica: o que foi feito, o que foi encontrado e os limites do estudo.

Ferramenta de publicação

Ciencia Util Publicacao é uma ferramenta interna, de uso exclusivo do dono do canal, que usa os Serviços de API do YouTube e a Content Posting API do TikTok para enviar os vídeos do próprio canal (no YouTube, com título, descrição, tags, miniatura e legenda; no TikTok, como rascunho). Ela roda no computador do dono do canal, não é oferecida ao público e não acessa contas de outras pessoas.

Ciencia Util Publicacao is an internal tool, used only by the channel owner, that uses the YouTube API Services and the TikTok Content Posting API to upload the channel's own videos (on YouTube with title, description, tags, thumbnail and captions; on TikTok as drafts). It runs on the owner's computer, is not offered to the public and does not access anyone else's account.
